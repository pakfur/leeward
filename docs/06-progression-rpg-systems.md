# Leeward - Progression and RPG Systems

## Character System

### Captain Creation
**Attributes:**
- **Leadership:** Crew morale and efficiency
- **Navigation:** Movement bonuses and weather reading
- **Gunnery:** Accuracy and reload speed
- **Tactics:** Special maneuvers and abilities
- **Diplomacy:** Port prices and faction relations

**Background Options:**
| Background | Bonus | Starting Perk | Special |
|------------|--------|---------------|---------|
| Naval Officer | +2 Leadership | Disciplined Crew | Military connections |
| Privateer | +2 Tactics | Plunder | Black market access |
| Merchant | +2 Diplomacy | Haggler | Trade route knowledge |
| Explorer | +2 Navigation | Cartographer | Hidden location maps |

### Captain Progression
**Experience Gain:**
- Victory in battle: 100-500 XP
- Completing objectives: 200-1000 XP
- Discovering locations: 50-200 XP
- Successful trades: 25-100 XP

**Leveling System:**
```
Level 1: 0 XP
Level 2: 1000 XP
Level 3: 2500 XP
Level 4: 5000 XP
...continues with increasing requirements
```

### Skill Trees

#### Leadership Tree
```
Command Authority
├── Inspiring Presence (+10% crew morale)
│   ├── Rally Cry (Ability: Restore morale)
│   └── Iron Discipline (Reduced desertion)
├── Efficient Orders (+1 Action Point)
│   ├── Quick Thinking (Faster ability cooldowns)
│   └── Tactical Genius (+2 AP once per battle)
└── Veteran Crew (Better starting crew)
```

#### Combat Tree
```
Master Gunner
├── Precise Aim (+15% accuracy)
│   ├── Broadside Expert (Full broadside bonus)
│   └── Long Range Specialist (Range penalty reduction)
├── Rapid Reload (-20% reload time)
│   ├── Chain Fire (Sequential shots)
│   └── Double Shot (Fire twice per turn)
└── Critical Strikes (+10% crit chance)
```

#### Navigation Tree
```
Master Navigator
├── Wind Reader (Better wind prediction)
│   ├── Storm Sailor (Reduced storm penalties)
│   └── Favorable Winds (Speed bonus)
├── Expert Helmsman (+1 Maneuverability)
│   ├── Emergency Maneuvers (Special escapes)
│   └── Ram Specialist (Ramming damage bonus)
└── Pathfinder (Reveal hidden routes)
```

## Crew System

### Crew Types
| Type | Role | Special Ability |
|------|------|-----------------|
| Sailors | Basic operations | Standard efficiency |
| Marines | Boarding combat | +Combat strength |
| Gunners | Cannon operation | +Reload speed |
| Officers | Command roles | Various bonuses |
| Specialists | Unique roles | Special abilities |

### Crew Experience
**Veterancy Levels:**
- Green: No bonuses
- Regular: +5% efficiency
- Veteran: +10% efficiency, +1 morale
- Elite: +20% efficiency, +2 morale, special perks

### Crew Morale
**Morale Factors:**
- Recent victories: +10-20
- Good supplies: +5
- Shore leave: +15
- Casualties: -5 to -20
- Defeats: -10 to -30

**Morale Effects:**
- High (80+): +10% all actions
- Normal (40-79): No effect
- Low (20-39): -10% all actions
- Critical (<20): Risk of mutiny
