# Fonts

All four families are licensed under the SIL Open Font License, Version 1.1. Each folder holds the
font files as downloaded from Google Fonts (github.com/google/fonts) and that family's `OFL.txt`.
The files are not renamed, modified or subset: several carry Reserved Font Names, and the OFL
forbids a modified version from using them. The licence must travel with the fonts; the fonts may
not be sold on their own.

Weights of the variable fonts are picked with `FontVariation` resources in `assets/ui/fonts/`
(`variation_opentype` on the `wght` axis), not with separate files.
